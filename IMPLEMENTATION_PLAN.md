# Implementation plan

This plan translates the proposal into code milestones. Calendar dates remain intentionally unset because the previously discussed working schedule was not present in the project workspace or identifiable in Drive.

## Milestone 1 — Experiment spine

- Define normalized interaction and track-feature contracts.
- Add per-user leave-one-out splitting with no held-out item leakage.
- Implement popularity, item-KNN, confidence-weighted matrix factorization, content, and hybrid interfaces.
- Implement Recall@K, NDCG@K, catalog coverage, and intra-list diversity.
- Verify the end-to-end flow on deterministic synthetic data.

## Milestone 2 — Dataset ingestion and audit

- Download both Kaggle datasets outside version control.
- Profile missingness, duplicates, play-count skew, user activity, and item popularity.
- Normalize `(track_name, artist)` keys and quantify exact, ambiguous, and unmatched joins.
- Produce a reproducible processed interaction table and acoustic-feature table.
- Freeze a development sample and a final evaluation sample.

**Exit criteria:** a data audit reports row counts at each filtering step, join coverage, leakage checks, and the final user/item/interaction counts.

## Milestone 3 — Strong baselines

- Scale popularity and item-KNN with sparse matrices.
- Implement/tune implicit-feedback matrix factorization.
- Standardize acoustic features and evaluate the single-profile CBM.
- Tune only on validation users; retain one untouched test split.

**Exit criteria:** reproducible tables for Recall@K and NDCG@K with fixed seeds and saved configurations.

## Milestone 4 — Proposed contributions

- Compare unweighted versus log-play-count confidence.
- Build multi-interest user profiles by clustering each user's listened-track features.
- Tune hybrid fusion weights and, if supported, confidence-aware adaptive fusion.
- Add novelty and long-tail exposure alongside diversity and coverage.

**Exit criteria:** each research question has a controlled ablation changing one design choice at a time.

## Milestone 5 — Analysis and final deliverables

- Estimate uncertainty across users or repeated seeds.
- Analyze cold-start/short-history users and popularity strata separately.
- Generate final plots, tables, method diagram, limitations, and reproducibility instructions.
- Run the final pipeline from raw inputs to report artifacts.

**Exit criteria:** every reported number is generated by a committed command and configuration; limitations explicitly cover dataset overlap, matching bias, offline evaluation, and scalability.
